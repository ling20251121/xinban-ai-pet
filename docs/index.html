    2. 02 · Check

      当面核对

      平静确认学生此刻是否安全、希望谁陪伴，并确认信息已经由真人接住。

    3. 03 · Choose

      共同选择

      和学生一起选下一步：倾听、休息、联系心理教师、监护人或应急服务。

    4. 04 · Reflect

      简要回看

      只记支持是否送达和下次跟进时间，不扩写隐私，不把心情变成标签。

    立即项不能仅在系统中“看过”：必须由现实中的可信任成人确认学生已被联系、支持已送达；存在现实危险时立即启动学校既定应急流程，并按情况联系 110 / 120。
