主模型：Qwen 北京

v4 全栈运行时以阿里云 Model Studio 北京地域的 Qwen 为主模型路线。该说明不表示本静态页面已经连接模型。

真实 API：仅服务端密钥

真实调用必须由部署管理员在服务端配置密钥。密钥不得写进浏览器 JavaScript、GitHub Pages、公开仓库、二维码参数或学生输入框。

网页不能代替现实中的人

本原型不是心理测评、诊断、治疗、自动转介或紧急服务。如果学生或他人正面临立即危险，请联系身边可信任的成年人并拨打 110；突发伤病拨打 120。静态页面不会替你通知老师。

教师端为什么不显示原文？

普通对话原文通常超出完成支持所需的最少范围，也容易引入误读和标签化。教师端只呈现匿名编号、结构化选择、时间和人工核对优先级。

正式试点还需要什么？

学校审批、监护人同意、学生本人同意、教师值守、供应商协议、服务端密钥治理、数据留存期限与可验证的危机送达闭环。
