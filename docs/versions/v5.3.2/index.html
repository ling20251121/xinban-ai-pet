DUAL-MODE ADULT DEMONSTRATION v5.3.2

保留完整学生界面，
也保留专业评估。

v5.3.2 不删除学生端和教师端，也不把它们变成静态截图。成年测试者可以在合成学校沙盒中操作完整界面；教师和专家也可进入独立评估路径，提交对固定合成案例和冻结 AI 输出的形成性评价。

共同边界：两条路径均仅限 18 岁以上成人。学生、学校、心情情境与处置线索均为虚构合成内容；禁止录入真实学生、学校或联系方式。本页只是固定版本说明，不联网、不登录、不收集数据。

MODE A · /LOGIN

完整学生／教师界面

  • 固定虚构账号与三种合成起始情境
  • 心情、Qwen 对话、ASR/TTS 与历史界面
  • 合成班级汇总和模拟教师处置队列
  • 学校域数据强制 synthetic=1

MODE B · /EVALUATE

教师／专家成人评估

  • 12 个固定合成学生案例
  • 一次性邀请码与匿名参与编号
  • 冻结 AI 材料、SUS、工作负担与安全评价
  • 评估表与学校沙盒表分离
双模式并存同一安全配置下，/login、学生端、教师端与 /evaluate 同时可访问。
23/23 通过全栈构建、权限、合成隔离、评估和沙盒回归全部通过。
地域如实披露评估存储位置由部署方配置；香港部署不得再写中国内地。
研究解释：完整学生界面用于让教师和专家看见、操作并评价产品体验，但操作者仍是成人，输入仍是合成情境。该记录不能当作真实中小学生效果或心理健康改善证据。
