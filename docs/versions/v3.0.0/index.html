历史固定版本 v3.0.0

心伴 AI-Pet
灵动语音研究原型

这一版把“关爱感”落在更清楚的选择、更细腻的状态反馈和及时连接真人上，而不是把 AI 塑造成会依赖学生的虚拟关系。v1、v2 的代码、入口与数据边界均保持不变。

当前发布边界：这里是不会收集输入的固定说明页。v3 全栈项目使用全新 D1，但公开部署不含 Qwen API Key；语音与真实模型调用需在学校审批后由管理员配置，不能在浏览器或 GitHub 中填写密钥。
更灵动的学生端心情反馈、状态化小狗微动、隐私优先保存、一次建议与明确会话收束。
语音输入与朗读30 秒、2.5 MB 的 Qwen3-ASR 转写；文字可编辑；AI 建议仅由学生主动使用设备朗读。
本地安全优先转写后立即运行本地危机规则；命中时不自动保存、不调用聊天模型，直接引导真人与 110/120。
中国模型路线首选阿里云 Model Studio 北京地域的 Qwen 文本与 ASR，密钥只在服务端。
原型级防护域名白名单、体积/格式/时长校验、限流、并发和重放保护；音频不写数据库或日志。
独立版本固定源码提交 87ecf0d；全新 Sites 项目和独立 D1，不读取或覆盖 v1 数据。
