CONTROLLED SCHOOL SYSTEM v5.0.0

真实持续对话，
边界由学校掌握。

v5 将学校账号、Qwen 持续陪伴、D1 记录、语音交互与教师最少必要支持队列组成一套受控全栈系统。学生不需要 OpenAI 账号或个人手机号，普通聊天也不向教师开放。

本固定入口是静态说明页：它不登录、不连接 Qwen 或 D1、不请求麦克风、不提交表单，也不存储任何信息；页面中没有服务凭据或真实学生数据。

02 · ACCOUNT学校发放账号用户名与密码，无公开注册
03 · CONSENT核验同意状态班级、年龄段与同意版本
04 · SUPPORT真实人员闭环最少必要队列与人工确认

STUDENT

连续而有收束的 AI-Pet 对话

学生在明确 AI 身份和剩余限额下持续交流；可主动语音转写、朗读、导出、删除或随时退出。

TEACHER

班级范围内的最少必要支持

教师查看聚合趋势和需真人处理的安全事件，不读取普通聊天原文；事件需现实中的值守人员确认。

DATA

D1 持久化与角色隔离

账号、班级、同意、会话和安全事件由服务端按身份与班级归属控制，不依赖浏览器自报身份。

MODEL & VOICE

Qwen 文本、ASR 与 TTS

模型密钥只在服务端；语音由学生主动触发。高风险表达会先被本地规则拦截，不进入普通模型对话。
15 分钟单次持续陪伴上限
12 回合学生发言回合上限
真人确认后才算送达系统不把“生成队列”冒充“老师已经收到”
真实实现不等于公开获批

本版本不表示已经获准采集真实未成年人数据或开展开放试点；论文展示应使用虚构或脱敏测试账号。

试点需要完整治理

学校和伦理审批、监护人及学生同意、值守流程、隐私安全评估、数据链路与适用登记备案均需先落实。

重要说明：心伴 AI-Pet 不是心理测评、诊断、治疗、自动转介或紧急服务。遇到立即危险，应联系现实中的可信任成人并拨打 110；突发伤病拨打 120。
