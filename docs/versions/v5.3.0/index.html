把真实学生留在门外。

v5.3.0 仅供 18 岁以上测试者扮演 3 个虚构学生或 1 个虚构教师。它让团队用全合成数据体验心情记录、Qwen 连续对话、语音输入与朗读，以及教师确认、跟进和解决的模拟闭环。

本固定入口只是静态归档：它没有登录、表单或脚本，不联网、不调用 Qwen、不读写数据库、不使用浏览器存储，也不包含账号、管理口令、API Key、音频、对话或研究结果。

TEACHER WORKBENCH

真的练习模拟处置

虚构教师只处理合成班级的最少必要线索，可练习确认、跟进和解决；这些动作不对应真实学生支持。
只允许 synthetic=1账号、班级、心情、对话和处置均明确标记为合成；凭据随机生成且不公开写入归档。
PII 在入口处拒绝疑似真实姓名、学校、班级、学号、电话、邮箱、地址或账号信息不进入存储，也不发送给模型。
不进入 /evaluate 研究结果沙盒体验记录与 v5.2.0 成人教师/专家评价流程隔离，不自动成为论文数据、学生试点数据或干预效果证据。
研究边界：v5.3.0 是成人操作的产品沙盒，不是真实学生试点。即使流程可以运行，也不得据此声称改善了中国中小学生的情绪、求助、学习表现或教师处置效果；真实未成年人使用仍需学校单位备案、研究/伦理审批、知情同意和独立的数据治理方案。
