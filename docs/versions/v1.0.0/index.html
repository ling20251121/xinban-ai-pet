全栈研究原型

这是首个具备学生记录、服务端模型适配、D1 持久化和脱敏教师汇总能力的技术原型。它用于说明系统架构与受控研究流程，不代表已经完成未成年人真实试点。

使用边界：当前托管入口可能要求 ChatGPT 登录，不适合作为中国学生公开入口。请勿录入真实学生姓名、电话、住址或未获同意的心理与健康信息。
学生端每日心情、可选文字与小目标；记录读取、导出和删除。
AI 对话服务端可配置 DeepSeek、豆包或 Kimi；未配置时使用安全示例回应。
安全边界明确危机表达先由本地规则拦截，不把 AI 当作心理诊断或紧急服务。
教师端密钥保护的聚合趋势与最少必要支持线索；普通对话默认不展示。
