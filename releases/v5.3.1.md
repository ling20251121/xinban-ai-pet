# 心伴 AI-Pet v5.3.1 — Sites/workerd 兼容修复

v5.3.1 是 v5.3.0 成人合成学校沙盒的兼容修复版本。它解决 Sites/workerd 对单次 PBKDF2 调用超过 100,000 次的限制，并记录已经完成与尚未完成的线上验证边界。

## 本版本变更

- 密码派生改为带 `v2` 版本标记的三段串行 KDF。
- 每段 PBKDF2 使用 70,000 次迭代，低于 workerd 的单次 100,000 次上限；三段总工作因子保持 210,000 次。
- 每一段的输出作为下一段的密码材料，并为每段派生独立扩展盐；不是三个可以互相替代或并行计算的独立哈希。
- 新格式与旧格式由盐前缀区分；历史固定归档不因本次修复被覆盖。

## 已完成的线上验证

- 成人合成沙盒成功初始化 1 个虚构教师账号、1 个合成班级和 3 个固定情境虚构学生账号。
- 学生账号登录已验证。
- 教师账号登录已验证。
- 合成班级的模拟安全队列读取已验证。
- 上述数据与操作均属于成人角色扮演的产品测试，不是真实学生数据、真实学校处置或研究成效数据。

## 尚未完成的线上验证

当前线上环境**尚未配置 Qwen 服务端 API Key**。因此本版本不能声称以下链路已经在线成功：

- Qwen 连续文本对话；
- Qwen ASR 语音转写；
- Qwen TTS 模型朗读。

未配置密钥时，这三条链路必须失败关闭，不能返回虚拟内容冒充模型结果。只有完成服务端密钥配置并逐条进行受控联调后，才能在后续新版本中记录相应的线上成功状态。

## 使用与研究边界

- 只允许 18 岁以上成人扮演固定虚构学生或虚构教师。
- 只允许完全合成的数据；不得输入真实姓名、学校、班级、学号、电话、邮箱、地址、账号或其他可识别信息。
- 沙盒记录不进入 v5.2.0 `/evaluate` 成人评价结果，也不能作为真实学生体验、干预效果、心理状态或教师处置效果的证据。
- 本版本不是获批的真实未成年人试点。若未来招募真实未成年人，仍需学校审批、研究伦理审查、监护人和学生知情同意，以及独立的数据治理与危机处置方案。

## 固定静态归档

`docs/versions/v5.3.1/` 是本版本的固定静态说明页。它没有表单、脚本、网络请求或浏览器存储，也不包含测试账号、管理员口令、API Key、音频、对话、模拟处置记录或研究结果。
