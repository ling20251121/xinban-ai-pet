# 心伴 AI-Pet v4.0.0 — 双端视觉工作台 / Dual-Surface Care Workspace

## 中文

v4.0.0 在不覆盖 v1、v2、v3.0.0 或 v3.1.0 的前提下，重做学生端与教师端的视觉层。学生端更接近安静、低压力的每日记录空间；教师端更接近只处理少量支持线索的工作台。它仍是 EITT 2026 研究原型，不是已经获准面向未成年人公开运行的心理服务。

### 本版变化

- 学生端采用柔和紫色、大留白的双栏布局：一侧呈现真实 `public/dog.svg` 小伴资产，另一侧完成每日心情记录。
- 不使用连续签到、等级升级、宠物离开惩罚或依赖性话术；一段会话以“保存记录、可选一次 AI 建议、需要时连接真人”收束。
- AI 建议仍默认关闭，由学生每次主动选择；语音转写和设备朗读保留告知、停止、取消、检查与降级状态，不自动播放。
- 教师端改为支持工作台，只显示匿名编号、班级聚合、结构化心情与支持级别，不显示姓名和普通聊天原文。
- 保留 Cue → Check → Choose → Reflect 人工核对流程；立即项必须由现实中的教师或其他可信任成人确认闭环。
- 桌面、移动端、键盘焦点、44px 触控目标和减少动态效果均纳入界面实现。

### 模型与密钥边界

- v4 全栈运行时的主模型路线是阿里云 Model Studio **北京地域的 Qwen**。
- 真实文本、语音或其他模型 API 调用必须由部署管理员在**服务端**配置密钥；密钥不得进入浏览器代码、GitHub Pages、公开仓库、截图或学生输入框。
- 未配置服务端密钥时，界面不得假装已经连接模型或完成转写，应明确显示不可用或安全降级状态。
- `docs/versions/v4.0.0/` 是纯静态界面与功能说明页：不请求模型 API、不连接数据库、不保存输入，也不发送危机通知。

### 数据与安全边界

- 本版不是心理测评、诊断、治疗、自动转介、纪律评价或紧急服务。
- 学生端是否请求真人支持与明确安全规则是教师端最少必要队列的来源；普通对话原文不进入教师工作台。
- 若学生或他人正面临立即危险，应立刻联系身边可信任的成年人并拨打 110；突发伤病拨打 120。网页不能代替现实求助。
- 真实未成年人试点仍需学校审批、监护人同意、学生本人同意、教师值守、供应商与跨境/跨区域数据链路审查，以及可验证的危机送达闭环。

### 验证范围

- v4 界面相关 TypeScript/React 文件通过定向 ESLint。
- Vinext 生产构建通过，学生端、教师端及既有 API 路由均可完成编译。
- 公开归档页另行执行 HTML、链接、Manifest 与禁用网络/浏览器存储 API 的静态校验。

## English

v4.0.0 refreshes the student and teacher presentation layers without replacing v1, v2, v3.0.0, or v3.1.0. The student surface uses a calm two-column daily check-in experience with optional one-shot AI advice and explicit reconnection to human support. The teacher surface shows only pseudonymous identifiers, aggregates, structured cues, and human-check priorities—never names or ordinary chat transcripts.

The primary full-stack model route is Qwen through Alibaba Cloud Model Studio in the Beijing region. Any real API call requires a server-side secret configured by the deployment administrator; no credential belongs in browser code, GitHub Pages, the public repository, or student input. The archived v4 documentation page is static and makes no model, database, storage, or notification request.

This release remains a research prototype rather than assessment, diagnosis, treatment, automated referral, or emergency response.
