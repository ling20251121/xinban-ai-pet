# 心伴 AI-Pet v3.1.0 — 双端公开演示 / Public Dual-Interface Demo

## 中文

v3.1.0 修正了 v3.0.0 公开固定入口只有版本说明、没有可操作学生端与教师端的问题。它不会覆盖 v1、v2 或 v3.0.0，而是新增一个可直接通过 GitHub Pages 打开的双端演示版本。

### 新增

- 学生端：心情选择、选填文字与小目标、一次性 AI 建议演示、记录回顾和真人求助入口。
- 教师端：完全虚构且脱敏的班级汇总、趋势、待核对支持线索与 CCCR 人工核对流程。
- 学生端与教师端可在同一网址中切换，支持移动端、键盘操作和减少动态效果。
- 语音输入与设备朗读提供交互演示，并明确标注公开演示不连接真实转写服务。

### 数据与安全边界

- 不发起网络 API 请求，不连接 Qwen、DeepSeek、豆包或 Kimi。
- 不连接数据库，不使用 localStorage、sessionStorage 或 IndexedDB；刷新后输入清空。
- 学生端输入绝不流入教师端；教师端数据全部为虚构样例。
- 不发送危机通知，也不声称已经通知教师；紧急危险时提示联系可信任成年人并拨打 110/120。
- 本版本不是心理测评、诊断、治疗、自动转介或紧急服务。

完整的数据库、教师鉴权和 Qwen 服务器端适配仍保留在全栈研究原型中；正式面向未成年人使用前需要学校审批、知情同意、教师值守与危机处置闭环。

## English

v3.1.0 adds a public, account-free student/teacher demo without replacing v1, v2, or v3.0.0. The page is fully static: it makes no API calls, persists no input, never transfers student demo text into the teacher view, and uses fictional de-identified teacher data. It is an artifact demonstration rather than an approved mental-health service or a live research deployment.
