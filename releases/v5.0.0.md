# 心伴 AI-Pet v5.0.0 — 受控学校账号与持续陪伴系统

v5.0.0 把此前的研究原型推进为受控学校场景下的真实全栈实现：学生使用学校发放的账号进入持续对话，教师在班级权限范围内管理账号和最少必要支持线索。它保留 v1–v4.0.1 的全部固定归档，不覆盖任何历史版本。

## 本版实现

- 采用**学校发放的用户名和密码**，不开放公开自助注册，也不要求学生提交个人手机号。
- 首位教师账号通过一次性的服务端受控 bootstrap 建立；此后由获授权教师创建、停用和管理本班学生账号。
- 账号、角色、班级、同意状态、对话和安全事件使用 D1 持久化，并由服务端会话校验身份与数据归属。
- 学生可以与明确标注为 AI 的 Qwen 心伴持续对话；每次陪伴会话最多 15 分钟、12 个学生回合，并在界面显示剩余时间和回合。
- 支持学生主动使用 Qwen ASR 语音转写和 Qwen TTS 朗读；语音功能不代替文本确认，也不自动播放。
- 支持导出或删除本人的对话记录，并提供随时退出、联系现实中可信任成人和紧急求助的明确入口。
- 高风险表达在调用模型前由本地确定性规则拦截，生成待真人处理的安全事件；危机情形不会继续普通 AI 对话。
- 教师端按班级显示聚合趋势和最少必要安全队列，不开放普通聊天原文；安全事件必须由现实中的值守人员确认和闭环。

## 受控使用边界

- 模型凭据只允许配置在部署环境的服务端，浏览器、静态归档和 Git 仓库中均不包含凭据。
- GitHub Pages 的 v5 固定入口只是静态说明页，不登录、不连接 Qwen 或 D1、不请求麦克风、不提交表单，也不保存任何记录。
- 本版本没有附带真实学生数据，也不表示已经获准面向真实未成年人公开试点。
- 正式试点前仍需完成学校和伦理审批、监护人及学生知情同意、账号与教师值守配置、隐私和安全评估、数据链路与部署地域审查，以及适用的生成式人工智能服务登记或备案核验。
- 对 14 周岁以下学生，必须先核验监护人同意；撤回同意、数据删除、事件送达和应急联系人流程需在学校方案中可实际执行。
- 本系统不是心理测评、诊断、治疗、自动转介或紧急服务，也不应声称“已经通知老师”，除非值守人员已经真实确认接收。

## 研究定位

v5.0.0 适合作为 EITT 论文中的“受控可运行研究系统”版本，用于说明学校账号、持续人机对话、语音交互、数据持久化、角色隔离和真人支持闭环如何组合。论文展示可以使用虚构或脱敏测试账号；真实学生研究必须在批准范围和明确数据治理方案下单独开展。

## English summary

v5.0.0 advances XinBan AI-Pet into a controlled, school-account full-stack system. It supports school-issued username/password authentication, a one-time teacher bootstrap, class-scoped D1 persistence, continuous Qwen conversations limited to 15 minutes or 12 student turns, opt-in Qwen ASR/TTS, student export/deletion, and a minimum-necessary teacher safety queue. The public archive contains no credential or real student data and does not imply approval for an open trial with real minors.
