# 心伴 AI-Pet v2.0.0 — 无账号静态安全演示 / Account-free Static Safety Demo

## 中文

v2.0.0 是面向 EITT 投稿展示、课堂演示和国内无账号访问场景制作的静态安全演示版。它不是 v1.0.0 全栈功能的替代品，而是一个刻意关闭数据上传、数据库和模型调用的公开展示版本。

### 在线版本

- 学生端：https://ling20251121.github.io/xinban-ai-pet/versions/v2.0.0/#student
- 教师端：https://ling20251121.github.io/xinban-ai-pet/versions/v2.0.0/#teacher
- 固定源码：https://github.com/ling20251121/xinban-ai-pet/tree/v2.0.0
- 源码提交：`e2f2039`

访问者不需要 OpenAI、GitHub、DeepSeek、豆包或 Kimi 账号。

### 已实现

- 学生可体验心情选择、可选文字、小目标和“希望真人关心”的交互流程。
- 提交后的记录只保存在当前页面的 JavaScript 内存中。
- 页面会显示固定的安全示例回应，用于展示产品语气和交互流程。
- 学生可以在当前页面查看和清空本次演示记录。
- 教师端展示预先写入的虚构脱敏班级汇总、趋势和支持队列。
- 学生端和教师端可通过页面标签切换，适合电脑和手机展示。
- 页面交互不调用应用后端、不连接数据库，也不调用任何模型 API。

### 明确不会发生的事情

- 不会上传或长期保存学生输入。
- 不会把学生端演示记录发送到教师端。
- 不会调用 DeepSeek、豆包、Kimi 或其他模型。
- 不会分析输入内容或自动识别危机。
- 不会登录教师账号或读取真实班级数据。
- 不会通知老师、家长、学校、110 或 120。
- “希望真人关心”的选择只出现在本页记录中，不会送达任何人。

### 重要限制

刷新页面、关闭标签页或离开页面后，本次演示记录即消失。教师端所有人数、编号、图表和队列均为固定虚构样例，不能用作研究结果、真实统计或干预证据。

本版本适合公开演示界面、研究构想和支持流程，但不能收集真实数据、测试真实模型效果或承担学生安全支持。即使页面不上传数据，也请勿在公共设备或展示现场输入真实个人信息。

## English

v2.0.0 is a static safety demo designed for EITT submission presentations, classroom demonstrations, and account-free access. It does not replace the full-stack capabilities of v1.0.0. Data uploads, database persistence, and model calls are intentionally disabled.

### Live version

- Student view: https://ling20251121.github.io/xinban-ai-pet/versions/v2.0.0/#student
- Teacher view: https://ling20251121.github.io/xinban-ai-pet/versions/v2.0.0/#teacher
- Immutable source: https://github.com/ling20251121/xinban-ai-pet/tree/v2.0.0
- Source commit: `e2f2039`

Visitors do not need an OpenAI, GitHub, DeepSeek, Doubao, or Kimi account.

### Implemented capabilities

- Students can experience the mood-selection, optional note, small-goal, and human-support-request flow.
- Submitted entries exist only in the current page’s JavaScript memory.
- A fixed safe sample response demonstrates the intended tone and interaction.
- Students can review and clear entries created during the current page session.
- The teacher view shows prewritten fictional, de-identified class aggregates, trends, and queue examples.
- Student and teacher views are accessible through page tabs and support desktop and mobile presentation.
- Page interactions do not call an application backend, database, or model API.

### What this release does not do

- It does not upload or persist student input.
- It does not send student-side demo entries to the teacher view.
- It does not call DeepSeek, Doubao, Kimi, or any other model.
- It does not analyze input or automatically detect a crisis.
- It does not authenticate teachers or retrieve real class data.
- It does not notify a teacher, guardian, school, police, or emergency service.
- Selecting “I would like human support” changes only the current page record and reaches no person.

### Important limitations

Refreshing, closing, or leaving the page clears the demo entries. Every count, identifier, chart, and queue item in the teacher view is a fixed fictional sample and must not be presented as research evidence, real statistics, or intervention outcomes.

This release is suitable for demonstrating the interface, research concept, and proposed support workflow. It cannot collect real data, evaluate a live model, or provide student safety support. Even though the page does not upload inputs, do not enter real personal information on a public or shared device.
