# 心伴 AI-Pet v5.3.2

发布日期：2026-08-12

## 结果

v5.3.2 在同一成人演示部署中保留两条清晰、独立的路径：

- `/login`、`/`、`/teacher`：18 岁以上测试者扮演固定虚构学生或教师，查看完整学生界面、教师界面，并测试合成心情、Qwen 持续对话、ASR/TTS 与模拟教师处置。
- `/evaluate`：成年教师与专家使用一次性访问码，对固定合成案例及冻结 AI 输出提交匿名形成性评价。

两边新增双向模式入口。学生与教师界面没有被删除，也没有被替换成纯静态图片。

## 数据与安全边界

- 学校域数据只允许 `synthetic=1`；登录者须确认已满 18 岁并只扮演虚构角色。
- 常见真实姓名、学校、班级、学号、电话、邮箱、地址与账号信息会被拒绝，但对外文案不声称自动识别可以覆盖一切。
- 学校沙盒表与成人评估表分离；沙盒运行记录不进入研究汇总。
- 评估数据的实际托管位置改为服务端必填的 `EVALUATION_DATA_HOST`，知情说明不再硬编码中国内地；香港部署必须如实披露香港节点。
- Qwen API Key、管理员口令、邀请码和研究密钥仍只允许存放在服务端 Secret 中。

## 推荐演示配置

```env
PUBLIC_DEMO_MODE=true
ADULT_EVALUATION_ONLY=true
SANDBOX_MODE=true
```

同时配置至少 24 字符的 `SANDBOX_ADMIN_KEY`、真实的 `EVALUATION_DATA_HOST` 及成人评估研究信息。部署必须使用新的合成演示数据库，不得复用真实学校数据。

## 验证

- Vinext 全栈构建通过。
- 完整回归测试 23/23 通过。
- 新增双模式同站回归：学生／教师沙盒与 `/evaluate` 同时可访问，并互相提供明确入口。
- 定向 ESLint 与 `git diff --check` 通过。

## 研究解释

本版本可以展示“真正可操作的学生端长什么样”，但操作者仍是成年测试者，输入的是合成情境。它可用于原型可用性与成人专业评价，不能写成真实中小学生干预效果、心理改善或真实学校有效性证据。

## 版本保留

v1.0.0 至 v5.3.1 的固定归档、标签和说明保持不变；v5.3.2 新建独立归档，不覆盖任何旧版本。
