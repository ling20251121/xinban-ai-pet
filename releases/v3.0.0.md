# 心伴 AI-Pet v3.0.0 — 灵动语音研究原型 / Caring Voice Research Prototype

## 中文

v3.0.0 在不覆盖 v1/v2 的前提下，新增隐私优先的交互状态、通义千问文本适配、30 秒语音转写、设备主动朗读和更明确的短会话收束。它仍是 EITT 2026 研究原型，不是已获准面向未成年人公开运行的心理服务。

### 已实现

- 默认主操作是“保存今天的记录”；AI 建议默认关闭，学生每次自行选择是否把本次文字临时发送给模型。
- 心情选择提供非诊断的即时反馈，小狗只使用中性微动，不用连续签到、离开惩罚或关系依赖话术。
- AI 每次只给一条短建议，并明确引导回到现实中的老师、家人或其他可信任成年人。
- 服务端新增阿里云 Model Studio 北京地域的 Qwen 文本适配，默认固定模型快照 `qwen3.7-plus-2026-05-26`。
- 新增 Qwen3-ASR Flash 语音转写：录音前单独告知，单次不超过 30 秒和 2.5 MB，转写后先由学生检查和修改。
- 音频只存在于一次请求内存，不写入 D1、R2 或应用日志；转写结果中的语言和情绪推断字段不被使用或保存。
- 转写文字返回前立即执行本地危机规则；命中时显示真人求助和 110/120 提示，不自动保存，也不再发送给聊天模型。
- 语音接口有原型级每客户端限流、每实例并发限制和短期重放阻断；Qwen 返回的计费时长必须存在且不超过 30 秒。
- AI 建议可由学生主动使用设备中文语音朗读；不会自动播放，紧急提示不提供自动朗读。
- 学生端去除情绪平均分和虚构趋势，保留记录天数和心情回看。
- 保留 D1 心情记录、查看/导出/删除、教师聚合与最少必要支持队列。

### 已验证

- Vinext 生产构建通过，包含 `/api/voice/transcribe`。
- ESLint 通过。
- SSR 与 API 自动测试 10/10 通过，覆盖跨源拒绝、格式/体积/时长、未配置失败关闭、本地危机优先、转写危机提示、原型限流与缺失计费时长失败关闭。

### 数据与部署边界

- v3 使用全新的 Sites 项目和独立 D1，不读取或覆盖 v1 数据库。
- 公开仓库和 Release 不包含 Qwen、教师或数据库密钥。
- 当前发布不配置真实 Qwen API Key；未配置时文本使用确定性安全示例，语音转写明确提示不可用。
- 手写容器时长解析只是正常浏览器录音的快速拒绝，不是可信媒体解码器。正式试点还需要平台级持久限流、全局预算、媒体网关和送达确认。
- 在中国大陆学校开展真实未成年人试点前，必须审查 Cloudflare/Sites 到阿里云北京地域的数据链路，并完成学校审批、监护人同意、学生本人同意、供应商协议和危机值守流程。
- 本版本不是心理测评、诊断、治疗、自动转介或紧急服务，不能用于成绩、纪律、升学或学生排名。

## English

v3.0.0 adds privacy-first interaction states, a Qwen text adapter, bounded voice transcription, user-triggered device read-aloud, and explicit session closure without replacing v1 or v2. It remains an EITT 2026 research prototype, not an approved mental-health service for minors.

### Implemented

- Saving a check-in is the default action. AI advice is off by default and requires a per-entry choice before text is temporarily sent to a configured model.
- Mood selection provides non-diagnostic feedback and neutral micro-interactions without streaks, separation penalties, or dependency language.
- Each submission receives at most one short AI suggestion and is closed by reconnecting the student with real-world support.
- A server-side Alibaba Cloud Model Studio Beijing Qwen adapter uses the pinned `qwen3.7-plus-2026-05-26` snapshot by default.
- Qwen3-ASR Flash transcription is limited to a disclosed 30 seconds and 2.5 MB, with editable text review before saving.
- Audio exists only in request-local memory and is not written to D1, R2, or application logs. Provider language and emotion annotations are ignored.
- Local crisis rules run immediately on the transcript. A match shows human-help and 110/120 guidance, is not auto-saved, and is not forwarded to the chat model.
- Prototype per-client rate limiting, per-isolate concurrency control, replay blocking, and a required provider-reported duration are implemented.
- AI advice can be read aloud only after a student actively requests the device voice. There is no autoplay, and urgent guidance is not auto-read.
- Student mood averages and fictional trends were removed.

### Verification

- Vinext production build passed, including `/api/voice/transcribe`.
- ESLint passed.
- 10/10 SSR and API tests passed, including origin, format, size, duration, fail-closed configuration, local-safety precedence, transcript safety, prototype rate limiting, and missing provider-duration cases.

### Boundaries

- v3 uses a new Sites project and a separate D1 database; it does not read or overwrite v1 data.
- No Qwen, teacher, or database credential is included in the repository or Release.
- The published build does not include a live Qwen API key. Text falls back to a deterministic safe example, and transcription reports that it is unavailable.
- Browser-container duration parsing is an early rejection aid, not a trusted media decoder. A real pilot still needs platform-level persistent rate limiting, global budgets, a trusted media gateway, and confirmed human escalation delivery.
- Any real mainland-China school pilot requires review of the Cloudflare/Sites-to-Alibaba-Beijing data path, school approval, guardian consent, student assent, provider agreements, and an staffed crisis-response procedure.
- This release is not assessment, diagnosis, treatment, automated referral, or an emergency service.
